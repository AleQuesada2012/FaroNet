FaroNet edge

FaroNet carries private messages inside a light-based mesh. This Cloudflare Worker is its public side: only messages explicitly marked public leave the mesh and appear here.

  • Public topic rooms: live WebSocket rooms, one per topic.
  • Topic feeds: /rooms/{topic}/feed.atom, the last 20 public messages of a topic for at most 24 hours.
  • Health check.

No accounts. The Worker stores no names, IP addresses or request logs; rate limiting counts requests in memory only. The hosting provider still sees connection metadata.
